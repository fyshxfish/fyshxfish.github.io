# Campfire ensemble

Seven independent traveler recordings were obtained from the fan project
[Traveler's Encore](https://travelers-encore.netlify.app/), by Aryan Pingle.
[Project source](https://github.com/aryanpingle/Travelers-Encore).

Original download URLs: `https://travelers-encore.netlify.app/music/<Name>.mp3`,
where Name is Esker, Gabbro, Solanum, Riebeck, Chert, Feldspar, or Prisoner.
The MP3 files are stored unchanged. All seven have the same encoded duration
(41.822041 seconds), sample rate (44.1 kHz), and channel count (stereo).

The music is from **Outer Wilds / Echoes of the Eye**, composed by
**Andrew Prahlow**. The source website credits Mobius Digital, Annapurna
Interactive and Andrew Prahlow; its code license does not relicense the music.

This work is unofficial Fan Content. It includes materials which are the
property of their respective rights holders and is neither approved nor
endorsed by Mobius Digital.

[Mobius Digital Fan Content Policy](https://www.mobiusdigitalgames.com/fan-content-policy.html).

The local player decodes all seven recordings, schedules them on one audio
clock and uses a shared loop length. Instrument switches change gain only.
Pause/resume restarts every source at the same shared offset.
